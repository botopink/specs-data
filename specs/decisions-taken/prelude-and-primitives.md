# prelude-and-primitives — what every program sees without an import

**The prelude is `primitives.bp` alone; a primitive is a lowercase type, a capitalised name is a contract several types share; `print` and `panic` are imported.**

(1) One prelude, `print` / `panic` imported, no `runtime` keyword, `compiler.src()` — 606, 609, 632, 718, 682.

(2) `any` removed; primitive types lowercase, contracts capitalised; `Pair` / `Function` removed; literal types never redeclared — 31, 617, 641, 738, 639, 873, 887.

(3) Behaviors: statics, signature checks, extension blocks, members added to a primitive — 628, 684, 799, 800, 872, 886, 974.

(4) The index expression, `at` / `slice`, negative index, `null` as absence — 30, 46, 47, 139.

(5) Primitive receivers answer declared methods only — 136.

(6) Body markers, whole return types, `Async.resolve` — 553, 570.

(7) The prelude of a `.bpp` is 589's — see bpp-files.
