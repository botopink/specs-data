# prelude-and-primitives — what every program sees without an import

**The prelude is `primitives.bp` alone; a primitive is a lowercase type, a capitalised name is a contract several types share; `print` and `panic` are imported.**

(1) **One prelude.** The types and behaviors a program reaches without an import — `Result`, `Task` (now `Async`, 553), `Component`, `Iterator` (now `Iter`), `Stream` (now `AsyncIter`), `Future`, `Use` — are declared in `primitives.bp`, registered before every module, and written bare everywhere — `Composition<T>` and `Composable<T>` with `Component<T>` among them, nominal to the checker (826) —; a local declaration shadows a prelude name, as it does `string` and `array` (606 (1), 641), a literal's type excepted (639, below). `TypeInfo` is no prelude name: it is `compiler.Info<T>`, declared in `compiler.bp` and imported by path (606 (3), 608, 630). No `#[builtin]`, no `@name`, no `compiler.setBuiltin`, no `builtin-twice` (606 (1); replaces 575 (2)). No `.d.bp` exists: the declaration-file kind is gone, every `.d.bp` renamed or dissolved into the std module that owns each declaration; a file still ending `.d.bp` is a module named `x.d` (575 (1)). Every builtin that remains is a declaration in std (252 as carried by 575 (1), 606).

(2) **Two std functions, imported where used,** inside std by the same import: `print(..values: unknown[])` in `io/terminal.bp` (`import {io.terminal} from "std"; terminal.print(…)`) and `panic(message: string = "panic") -> noreturn` in `failure.bp`, beside `Failure` and `attempt` (606 (2)). `println`, `debug` and `todo` are removed (`println(a, b)` is `print(a, b, "\n")`, `todo()` is `panic("not implemented")`); `src` is `compiler.src()` (606 (2), 718). `print` is an effect and never folds at build (632, 682).

(3) **Primitive types are lowercase and are types:** `i32`, `i64`, `u32`, `u64`, `f32`, `f64`, `bool`, `string`, `bigint`, `bytes`, `array<T>` (`T[]` stays the spelling of `array<T>`), declared `pub type … implement <contract>` in `primitives.bp`; neither `Pair<A, B>` nor `Function` exists — a pair is the tuple `#(A, B)` (`#(a, b)`, `p._0`, `val #(a, _) = p`), and `identity`, `compose`, `flip`, `constant` are plain functions of std's `functions.bp` (738); a capitalised name is a contract shared by several types (`Number`, `Integer`, `Signed`, `Float`); `String`, `Bool`, `BigInt`, `Bytes` and `Array` dissolve into their types, which hold their methods and statics (641, 617 (1)). A primitive type's body declares a property as `pub val length: i32;` (887), a form `primitives.bp` alone takes; a local named like a primitive type shadows its statics in its body (606 (1)); a module-level `fn` or `val` of such a name — `array` included, std's `json.array` being `json.arrayOf` — is `primitive-type-name-taken`; a failed `toUtf8` answers `bytes.toUtf8: not valid UTF-8` (873). A behavior holds signatures and `default fn` bodies in botopink, never a cell — the body is the algorithm for every type that does not override it (617 (2)); host code lives on the type, `#[compiler.external(…)] declare fn toString(self: Self) -> string;` inside `pub type i32 implement Signed { … }`, `Self` concrete (617 (3)); a type overrides a `default fn` by declaring the member itself (617 (3)); every implementor is checked against its contract on every member, required or overridden, std's and a program's, an extension block's included: the same number of parameters, each parameter's type and the return type identical with `Self` read as the implementing type — no variance —, labels, parameter names and defaults free, a difference refused at the member, `implement-signature-differs`, naming both signatures (800); identical is read over types, not spellings — an alias and its target, `array<T>` and `T[]`, a wrapper with or without `@` are one type —; a member's own type parameter inside `Self<…>` takes the clause's argument (8 A1); a parameter's `comptime` marker is part of the signature, a body marker (`component`, `async`, `iter`) staying outside it (571, 809 (2)), and a member's own type parameter is not counted (871, 883); `implement-with-body` holds on every bodied declaration, a behavior's `default fn` included (617 (4)). A static with a cell is the type's static — `string.fromCodepoint(65)`, `array.range(0, 3)`, `bytes.fromUtf8(s)`, `bigint.of(…)` — declared on the type, never on a behavior; a contract may list a required static (`fn make() -> Self;`) each type provides (641). In a `behavior`, a member without `self` is a static of the behavior and is written `fn`, never `default fn`: `fn unit() -> Self { … }` with a body is the behavior's own function, `fn make() -> Self;` without one a static each implementor provides; `default fn` is an instance member with an overridable default body; `default` on a member without `self` is refused, `default-on-static` (628). A module declaring a type named like a literal's type (`i32` … `bigint`) is refused at the name, `primitive-type-redeclared` — the structural exception to shadowing, exactly the types the language gives to literals (639). A type that implements a behavior only through an extension block (`Sym implement B for T`) is not a value of that behavior (684). There is no `any` — no type turns the checker off; `unknown` is the host vocabulary's spelling, narrowed with `is` before use (31). A primitive receiver answers only the methods its type declares — a `fn`, a `val`, `len` / `size` for `length`, an `extend` block's — and those of every contract implemented for it in scope, a program's included: std's `pub type string { … }` keeps the type's own methods, and a program adds members beside them through a contract of its own, `behavior Shout { default fn tailShout(self: Self) -> string { … } }` then `StringShout implement Shout for string {}`, never a lowercase `behavior string` nor `extend` on a primitive; a member the type already has is `behavior-member-redeclared` at the implementation (799); that is a contract's bodied `default fn` the type already has; a required member the type has is met by the type's own method, compared with the contract's signature as any implementor's (800, 872), a `pub` one unless the block is the type's module's, else `method-not-pub` at the block (886); anything else `unknown-primitive-method` at the name, suggesting the declared method whose host spelling or near name was written; a host spelling (`toUpperCase`) is no method of the language (136). An index is sugar for a method call and has no typing rule of its own: `xs[k]` is `xs.at(k)` and answers `?T`, `d["k"]` is `d.at("k")`, `xs[a..b]` is `xs.slice(a, b)` and `xs[a..]` `xs.slice(a, null)`; `at` and `slice` come from the ambient behaviors `Index<K, V>` and `Slice<V>` of `primitives.bp`, which `array<T>`, `string` and `Dict<K, V>` implement and any type may (63, 46, 30); a tuple's constant index is the checker's own case (63, 139); an absent index or key answers `null`, the one spelling of absence (47); a negative position counts from the end on `array` and `string` alike — `xs.at(-1)`, `xs[-1]`, `"abc".at(-1)` —, `Dict.at` by key (139).

(4) **`Result` and `Async`:** `Result<R, E>` is declared once, in `primitives.bp`, with its five methods as `case` bodies over `Ok` / `Error`; the checker binds the type form to that declaration; every backend keeps 118's value shape (`{ok, V} | {error, E}` on erlang and beam, `{ ok: V } | { error: E }` on commonJS); no inline lowering of the methods (609, 575 (7)). std gives `Async.resolve(v: T) -> Async<T>` (570).

(5) **The prelude of a `.bpp`** (`rakun-bpp`'s) is 589's — see § bpp-files.
