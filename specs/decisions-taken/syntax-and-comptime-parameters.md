# syntax-and-comptime-parameters — how an argument arrives

**`comptime x: T` is a value known at build; `syntax x: T` is the code as written, never executed at the call; a `-> anytype` / `anyvalue` function builds a type or code; `#[f]` and `f(e)` read one kind of function.**

(1) The two modifiers, type tokens and binding — 364, 412, 417, 667, 668, 716, 720, 735, 757, 758.

(2) Trees: `compiler.*` evaluated at build, `Field`'s run-time form — 614, 631, 642; 638 reversed by 802.

(3) Expansion at the call; a `syntax` function as decorator or call — 562, 581, 695, 719, 756, 841, 962, 976, 986; 907 replaced by 976.

(4) Building types and code: `anytype`, `anyvalue`, templates — 578, 670.

(5) `comptime` expressions, blocks and lifting — 255, 266, 331, 525.

(6) `comptime var`, a variable of the build — 807.

(7) cardume's value-or-type parameter — 297, 736.
