# std — the standard library's surface

**std takes the natural name; one value on every target; a module that can fail answers its own error enum; what is generic goes to std and nothing library-specific.**

(0) **Shape.** std is three categories: a pure root — same input, same output; no clock, disk, network or entropy —, `io/` (everything that talks to the world outside the process) and `testing/` (the harness, entered only under `botopink test`); a root module imports nothing from `io/`, refused by the compiler; `erlang.bp` and `beam.bp` are the BEAM targets' surface outside the criterion and exist only on those targets — importing one off the BEAM is `std-unsupported-on-target` at the import (106, 43); a merge only where the new name wins (`collections`, `hash`, `encoding`); a directory groups function modules and a file groups types, so `Dict`, `Set`, `Queue` and `Order` are `collections.bp` and their constructors are type-scoped — `Dict.empty()`, `Set.fromList(xs)`, `Queue.empty()` (106, 111). `encoding` is the one percent and form codec (`percentEncode`, `percentDecode`, `formParse`, `formStringify`) and `escape.scriptJson` the escape for JSON inside a `<script>` element (`&`, `<`, `>`, U+2028, U+2029) (116 (4), (8)).

(1) **Collections and text.** `Dict.ofEntries(entries: #(K, V)[]) -> Dict<K, V>` (`T[]` the spelling of `array<T>`, 641), a repeated key keeping its last value (174); `Dict.bump(key, by)` for an integer `V` alone, an absent key counting from 0, a non-integer `V` refused at the call, located, the written read-modify-write `counts.insert(k, (counts.at(k) ?? 0) + n)` staying refused (340, 534); an array's `unique()` (`array<T>`, 641) removes every duplicate keeping each value's first occurrence, compared with `==` (217); `string.fromCodepoint` (262); the three generic text methods and `io/fs.mkdirRecursive` (402); `string.parseInt()` answers `Error` beyond `i64` (176). std takes the natural name and a library's copy goes — `clock.parseDuration`, `async.RetryPolicy`, `async.nextDelay` (170). `io.random.bool()` is dropped; `coin()` is the boolean draw (250). `hash.pbkdf2Sha256(password, salt, iterations, length)` derives over the salt's UTF-8 bytes, the same on node and erlang; `iterations` or `length` < 1 panics with one text (175, 197 (3)). `async.retry` with an unusable policy panics (`maxAttempts` < 1, a negative delay, `maxMillis` > 2147483647, `multiplier` < 1.0), as `race([])` does; `nextDelay` answers `null` for it (197 (2)). `math` — § backends-and-run-time-output (259, 263); `unicode.normalize` (333 (A)). `regex` has one test: `Regex.compile(pattern)` answering `Result`, then `r.matches(input)`; the free `regex.matches(pattern, input)` goes (918).

(2) **`io.fs`,** on Rust's, Java's, Erlang's and Node's common shape. `pub type FsError { NotFound(path), PermissionDenied(path), IsDirectory(path), NotDirectory(path), AlreadyExists(path), InvalidUtf8(path, offset: i64), Other(path, message) }` — the same OS error the same variant on every target; every `io.fs` function answers `Result<…, FsError>`, never a `string` error (540 (1)); `pub fn message(self: FsError) -> string`, one text per variant (`not found: <path>`, …, `<path>: <message>` for `Other`); a library carrying an `io.fs` failure into a `string` writes `e.message()` (563). Whole-file shortcuts `readBytes`, `readText` (UTF-8 checked, `InvalidUtf8` on every target), `writeBytes`, `writeText`, `appendText`, `stat` (`size: i64`, `mtime: i64` whole seconds on every target, `isDir`), the directory functions (`exists`, `list`, `mkdir`, `mkdirRecursive`, `rm`, `removeTree`, `copy`, `walk`, `glob`); the write and directory functions answer `Result<void, FsError>`, `File.write` alone a count (540 (2), 499, 711 (4)). The handle: `open(path) -> Result<File, FsError>`, `create(path)`; `File implement Closeable` with `path()`, `size()`, `read(n)`, `bytes()`, `text()`, `chunks(size = 65536) -> AsyncIter<bytes, Result<void, FsError>>`, `lines() -> AsyncIter<string, Result<void, FsError>>` (ending at an `InvalidUtf8` line), `hash()` (SHA-256 lowercase hex, the whole file whatever the read position), `write(b)`, `close()`; closed by the writer with `defer`, unchecked (540 (3), 553 (6), 711 (2), (3)). Every target: commonJS `fs.*Sync`, erlang / beam `file:*`, wasm `wasi:filesystem` with `needs: [.Filesystem]`; on the browser host a call reaching `io.fs` is refused at the call (540 (4)). `fs.glob`: `*` and `**` do not match a name starting with `.` unless the pattern writes the dot; the walk does not descend through a link to a directory; a final `**` is every entry at every depth, the root excluded; a trailing `/` keeps real directories only; a `..` segment is a literal name; a `{a,b}` alternative holding `/` matches nothing (177, 197 (4)). A dangling link under `walk` answers `NotFound(<root>/<link>)`, `path` naming the link (711 (1), 178). `mkdirRecursive`: every missing directory above the path is made, one that is there is `Ok`, a file in the way an `Error` (402). `fs.openAsset` is gone; an `Asset` opens a `File` (607 — § assets-and-embed).

(3) **`io.clock`, `io.process`, the CLI's primitives.** `io/clock`'s domain is the epochs RFC 3339 writes (0000-01-01T00:00:00Z … 9999-12-31T23:59:59.999Z); `formatIso8601`, `toCivil`, `offsetMinutes` abort past it, naming the value, on every target (497); `formatIso8601` writes milliseconds always, `.sssZ` (849); `clock.parseDuration` keeps its 2^53 − 1 ms bound — a duration is handed on as an `f64` (498). std gains a CLI's host primitives, the same on commonJS, erlang and beam, a located refusal on wasm: `io.stdin` (`readLine() -> Async<?string>`, `isTTY()`), `io.terminal` (`stdoutIsTTY()`, `size() -> ?#(i32, i32)`, `setRaw(on)`, `keys() -> AsyncIter<Key>`), and in `io.process` `enum Signal { Int, Term, Hup, Winch }`, `onSignal(s, f)`, `spawn(cmd, args) -> Result<Child, ProcessError>` with `Child.wait()`, `kill(s)`, `forwardSignals()` (506 (1)); `keys()` is lazy on erlang and beam as every `AsyncIter` is (B-128, 855); `setRaw` and `size` are Linux's there, `Error(Unsupported)` / `null` elsewhere (856); `onSignal(.Int, f)` answers `Error(Unsupported)` on erlang and beam, where the VM keeps `SIGINT`; `forwardSignals` skips `Int` there (688); `io.process.start(cmd, args, cwd, env)` — `env` `NAME=value` entries added to the parent's environment, no shell, a malformed entry `Error(Other(…))`, the output back as `Captured.wait() -> Async<Exit>` (798 (6)) — exists on commonJS alone: a call reaching it on erlang, beam or wasm is refused at the call, `std-unsupported-on-target`, the module importable and `run` / `spawn` unchanged (906); on erlang and beam a spawned child runs behind a port — its stdin a pipe, its stderr merged into stdout — documented in `libs/std/AGENTS.md` (689). The `cli` library (`botopink/cli`, `from "cli"`) builds over them: commands types-first (a record with `#[cli.command("create", about: …)]`, fields `#[cli.arg]` / `#[cli.flag(short: "p")]`, subcommands an enum, `cli.parse<RakunSsr>(env.args())` (893), `--help` generated), style as plain composable functions (`cli.style.green(s)`, nothing emitted under `NO_COLOR` or when stdout is no TTY), prompts one awaited function per kind (`cli.prompt.text(msg)`, `confirm`, `select`; with no terminal an error naming the argument to pass, never a wait) (506 (2)).

(4) **`io.http`, async, testing.** `fetch(req: Request) -> Async<Result<Response, HttpError>>`, one typed surface (623, 334 (4), 393; 623's `Task<…>` reads `Async<…>`, 732); `HttpError.NotAllowedOnHost` on the browser host (335 (1)). Concurrency fixes results, never interleaving; no cancellation (335 (2), 704); `testing/mocks`' registry in the wasm module's memory (335 (3)); `testing.asserts` imports on wasm (503); `asserts.throws<T>` and `attemptTask` (493, 494); no test lifecycle hook: nothing implicit runs around a `test` block; a test body calls its reset helper (706); `testing.snapshots` left for `snap` (391, 407). std's test-only cells (`monoMillis`, `hostTarget`, `newCounter`, …) stay unbound on wasm until `botopink test` runs wasm (690). Every std module that can fail answers its own error enum and every binding is audited (486, 495 — § result-and-failure). std's `bpp` module holds the four role annotations (361 — § bpp-files); std's `context` module `createContext`, `provide`, `context`, `inject`, `Scope`, `Place`, `resolve`, `run`, `all` (`Composition`, `Composable`, `Component` the prelude's, 826) (378, 388, 416, 809, 811 — § contexts-and-components); `failure.attempt`, `Failure`, `HostError` (431, 489); `types.Type` (307, 630); `compiler` (579); `code` (637); `testing/mocks.mock` (644); `Closeable` (539); `Async.resolve` (570); `Iter`'s helpers (596); `Decimal` (332). std declares `Any` on its pure primitives (376 (4), 681). std's `#[compiler.external]` cells are the model for every library's (575 (6)).
