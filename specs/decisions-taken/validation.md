# validation — `#[validated]`, the field markers, coercion, JSON Schema

**The type is the only schema: `#[validated]` both checks and parses; what only a value could say is a field marker; every failure is a `ValidationReport` with each violation at its path.**

One decorator: `#[validated] pub type Signup(#[email] email: string, age: i32)` both checks (`validate()`, `constraints()`) and parses — the members `Player.parse(doc)` (`Json` → `Result<Player, ValidationReport>`), `parseAt(doc, at)`, `decode(text)`, `bind(pairs)`, `encode(p)`, `jsonSchema()`, carried with the type to every importer; the module-level functions named after the type go; `Schema<T>`, `Codec<A, B>`, the `schemas.*` combinators and the `checks.*` functions leave the public API — private machinery the emitted decoders call (306, 327). Field markers: `#[each(email, lowercased)]`, `#[codec(decode: isoToMillis, encode: formatIso)]`, `#[map(f)]` / `#[tryMap(f)]`, `#[preprocess(f)]`, `#[refine(rule)]` (its violation `custom`, its text from the field's message order); a one-field record encoded as its field is `#[validated(transparent)]`; an ad-hoc union or tuple is a declared type; a row of `surface.md` no declaration says naturally is a marker where one reads well, else `n/a (306)` (306, 406 (2)). `#[check]`'s `message` comes first and is required: 406's parameters in order — the annotated declaration, then `message` (first and required), `rule = null`, `at = null` (a `compiler.Field<T>`), `code = .Custom` (in 575 (4)'s spelling by 731 (11): `check<T>(syntax decl: T, comptime message: string, comptime rule: ?fn(v: T) -> bool = null, comptime at: ?compiler.Field<T> = null, comptime code: ViolationCode = .Custom)`; `rule == null` is an ordinary test, 735) — `#[validated, check("As senhas não batem", passwordsMatch, at: .confirm)] pub type Account(…)` and `#[check("…")] fn passwordNotHandle(a: Account) -> bool`; a check without text does not compile; `#[check]` on a field is refused, naming `#[refine]` (406 (1), 244). Several `#[check]` on one type each record a `Check` meta and `#[validated]` writes the one `validate`, iterating `comptime compiler.typeInfo(T).metaAll(Check)`, checked pre- and post-comptime, its library names resolved in `validation`'s module (404, 395, 384). Another library takes the type, never a schema value — a `comptime` type parameter, refused unless `compiler.typeInfo(T).meta(Validated)` is present (306). A `#[validated]` record refuses a key it does not declare — `unrecognizedKey` at the key's path; `#[stripUnknown]` and `#[rest]` are the two located ways to say otherwise (144). Every failure — a constraint or a decode — is a `ValidationReport` with each violation at its path; std knows nothing of validation (257). Coercion is a grammar per target type, the same on erlang and commonJS: `bool` reads the `stringbool` set, a number the integer grammar with a fraction and an exponent, `""` and `null` absent, anything else `invalidType` (183); `#[validated]`'s bind reads a field by its own type (`i64` exact, `bigint` any integer, `Decimal` any number exactly, `f64` rounded); a string becomes a number only under `#[coerce]` (332 (5)). Front 125 is all of Zod in 306's shape, every step in order (325). The JSON Schema documents are checked against the 2020-12 meta-schema by a vendored Ajv in the tests only, through `io.process.run("node", …)` on commonJS; never in `src/`, never shipped (399). `compiler.Field.defaultValue` gives validation's decode the fallback it writes (598). A framework that adds fields to a form drops them before the type sees the pairs (144). The message lookup is injected: `validation` resolves a template from the `MessageSource(locale, template)` it is handed — `<locale>.<code>`, then `<code>`, then the built-in text —, set by the framework at boot; the library spells no framework key (116 (5)).
