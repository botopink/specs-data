# gate-and-ci — the gates, the pool, the pipeline and landing

**`scripts/gate.sh` is every repository's one gate; the commit hook runs it without conformance, the pipeline with, after, and nobody waits; the meta `scripts/gate.sh` schedules the machine's gates under one pool.**

(1) **One gate per repository.** `scripts/gate.sh` in every repository — botopink-lang its own; each library a short file identical across the libraries (CI check 4) running the shared `runner-standalone.sh`; the meta repository the checks of `hook-integrity.yml`, runnable locally; the pre-commit hook and the workflows call it — one source (466 (2)). `scripts/gate.sh --no-conformance` is the commit hook's gate: on a `front/*` branch the step gate — the build, `zig build test`, `test-cli`, and the `test-libs` libraries the step reaches, chosen by the backend partition; a change in a shared file runs all; the branch decides the mode, never a flag (460, 470 (1), 249). A gate run with `--no-conformance` takes no lock and is admitted at once (508). The pipeline runs `scripts/gate.sh` with conformance on every push to `feat`: a check after the fact; a red there opens a structural fix at once, never a revert; nothing is marked passed that did not run (470 (3), 466 (3)). A library's pre-commit hook that cannot find the compiler refuses the commit, and refuses a staged `*.snap.new` / `*.snap.md.new`; one hook text across the libraries (161). A library's CI matrix is its manifests' target set, every row hard; no row for a target `botopink test` cannot run (162). The commit hook formats the commit's `.bp` files (524). `expected-failures.txt`, `known-broken-examples.txt`, `restricted-targets.txt`, `known-red-libs.txt` are gone; a red cell is red (154, 161, 153). `test-libs`' restriction audit matches a refusal's id, `host-binding-missing`, never its text (920).

(2) **Landing.** A front lands on `feat` — its steps pushed fast-forward, never forced — once its commits passed their hook gate; conformance is not a precondition to join `feat` (477 (1)). Its Conformance step waits on `feat`'s pipeline run and reads, with `gh` (read only), `feat`'s runs since the front's base: green on every row → done; red → reproduced locally (conformance runs locally only then), fixed at once as a structural fix ahead of every other step, with the cheap test that would have caught it written beside the fix, pushed, read again — never rerun until green, never marked passed; a red that predates the front is filed as its own row (477 (2), 474, 478). A front's Conformance step holds back no front that builds on it; a front already building on the change rebases on the fix (479). No `front/*` branch goes to GitHub (477 (3)). A push to `feat` runs in a CI concurrency group of its own commit, so every commit runs to the end; pull requests keep `cancel-in-progress` (528). A thread fetches and rebases onto `origin/feat` right before its final commit; `scripts/land-check.py` checks a branch before it lands (484 (2), (4)).

(3) **The pool.** A machine-wide job pool replaces the one-gate-at-a-time lock: every gate the coordinator runs draws its jobs from one pool at a fixed per-machine path, structural, never a flag; a stage takes a token per job and returns it; a gate's `test-out` is written under a directory of its own run (468). The pool and the scheduling live only in the meta repository's `scripts/gate.sh`: `scripts/gate.sh [check]`, `run <repository|task>…`, `tasks`, `libs`, `status`, `exec [--jobs <N>] <name> -- <command>…`; it finds the tasks by `git worktree list`, telling a task's own repository from its linked siblings; a repository's gate knows no pool and no lock, takes a total of jobs and offers `--no-conformance`; it runs and reports, landing stays the coordinator's; each run's log is scratch (469, 473). The capacity is `max(1, min(cpus / 2, (MemAvailable − 2 GiB) / 768 MiB))`, read on every pass of every admission; the CPU half is never applied to the memory bound; 2 GiB always stay free; below the margin no new gate is admitted while one runs; one job always exists (674). Admission is first come, first served, with one exception: while the pool is not empty, a gate asking for fewer jobs than the capacity may pass older waiters that all ask for the whole pool, at most one such pass in flight; a full-pool gate starts only on an empty pool; `scripts/gate-test.sh` tests it in a private pool, its two environment overrides the test's alone (717). Measuring a gate's time waits for the pool to be empty (468 (5)). The cold budget is 7m30s; over budget is a yellow line, never a red (265). `test-libs` given several `--lib` runs every one, in order, in one report (258).

(4) **CI of botopink-lang.** `build.zig`'s glibc target is 2.35, checked by `objdump -T` (219); `test.yml` builds and runs every stage after the unit tests with `-Doptimize=ReleaseSafe`, `zig build test` staying Debug (226); the macOS rows install `erlang@28`, the linux rows pin `otp-version: '28'` (227); `test-web` is a gate stage (231); the windows row is deleted, not soft, until the snapshot capture normalises CRLF and path separators (158). The compiler emits for one exact OTP release (28, printed by `botopink --version`); `build`, `run` and `test` on erlang or beam refuse another `erl` on `PATH`, and `gate.sh` and the workflows take the release from the compiler (228).

(5) **The meta checks** (`scripts/gate.sh check`, CI's `hook-integrity.yml`): every submodule pointer an ancestor of its remote `feat`; every § Layout path on disk; no `*.snap.new` / `*.snap.md.new` / `todo.md` tracked; the libraries' hooks one text; every `// LANGUAGE GAP` marker in the milestone's `language-gaps.md`; every `repository/<repo>/decisions-taken.md` exactly what `scripts/decisions-split.py` writes — each repository carries a generated ledger of the decisions whose Binds name it, English only, never edited by hand, with the `Cell` column (482, 647); every decision cell's directory a slug of its ledger, with `docs.md` and `draft/main.bp` or `src/main.bp`, never both, never neither (647, 648, 649, 650). A commit whose only change is the generated ledger skips the hook — the maintainer's exception of 2026-10-15, stated in `scripts/thread-rules.md` and recorded by no row yet.
