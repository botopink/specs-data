# request-state-and-cookies — atoms, cardume, `Cookie<T>`

**Request state is atoms read and written through `use`; a cookie is declared once, typed, its hooks nouns in cardume's family; `cardume` is a library of its own with Recoil's model in botopink's spelling.**

`pub val currentUser = atom(…);` declares a request-scoped atom of any `T` — cardume's `Atom<T>` —, its identity the declaration, no string key; middleware writes `val setUser = use atomSetter(currentUser); setUser(u);`; a page, component, handler or action reads it with `use atomValue(currentUser)` → `?User`; middleware, route handlers and actions are `component` bodies answering `Component<Response>` so they may `use` (553 (1)); the request is the root context `RequestContext`; `LocalKey<T>(name)` is gone (295). `cardume` (`repository/cardume`) holds Recoil's model: `atom`, `selector` (sync and async), `atomFamily` / `selectorFamily`, `Loadable`, `transaction` (synchronous, atomic, atoms only), `atomCallback`, `snapshot`; one atom type, two places to live, both in `rakun-cardume` (893) — a store per request, a store per page in the browser, shared by its islands —, each store spelling the same hooks (`atomValue`, `atomState`, `atomSetter`, `atomReset`, `loadable`, `transaction`) reading the store from a root context its framework provides (296). A `comptime` parameter may accept a value or a type — cardume's hooks take an `Atom<T>` value or a type naming its implicit atom (one per type per store, valued `?T`, or `T` when the type declares a default, `#[atom(default: Theme.Light)]`); no overloading; a declared atom stays the way to hold several values of one type (297, in 575 (5)'s spelling: `comptime source: Atom<T> | type<T>`, the body testing `source is type<T>` — 736). A cookie is declared once, typed: `pub val sessionCookie = Cookie<SessionId>("session", httpOnly: true, secure: true, maxAge: days(30));`, `Cookie<T>` in `http`, `T` one it can encode; middleware, route handlers and actions write and clear it, the attributes from the declaration; a render writes none (294). Its hooks are nouns: `use cookieValue(sessionCookie)` → `?T` (`null` when absent or undecodable), `use cookieState(sessionCookie)` → `.value` / `.set(v)`, `use cookieSetter(sessionCookie)` → `fn(v: T)`, `use cookieReset(sessionCookie)` → `fn()`; a page reads only — `cookieState`, `cookieSetter`, `cookieReset` in a render refused at build (400). `cookieValue` is `#[serverOnly]` (294). An atom holds any `T`; an island's read set is checked at build over the hooks list, and an atom an island reads whose `T` is not encodable (354 (6)) is declared `#[clientOnly] pub val draft = atom(…);`, else an error at the island's `use` naming the atom and `T`; a `#[clientOnly]` atom read on the server is refused at the `use` (943). No atom effect ships in the first cut; `persistLocal` / `syncSearchParam` are a later step after a measured need, keyed by the declaration (944).
