# snap — the snapshot engine

**`snap` holds the path rule, the `.snap` format, the check and the `.new` flow; std provides only the general primitives it is written over; a new `.snap` exists only where its bytes are a contract another package reads.**

`snap` (`botopink/snap` at `repository/snap`) holds `<dir of loc.file>/__snapshots__/<suite>/<slug>.snap`, its slugifier, the `botopink-snap 1` format (a header — `botopink-snap 1` / `test: <name>` / `subject: <helper>` —, a blank line, the body; one slugifier, the compiler's, for the compiler's snapshots and the libraries' alike, 72), the check and the `<path>.new` flow (a person renaming `.new` accepts; no update flag), `assertText`, `assertAs`, `assertNamed`, `assertNamedAs`; `testing.snapshots` left std with no re-export — `import {testing.snapshots} from "std"` answers the plain `error: unknown "std" module 'testing' in import`, the pointer to `snap` (`import {assertAs} from "snap";`, `"snap"` in `"dependencies"`) being documentation (407); std's four `.snap` moved with the engine (391 (1)). std provides `compiler.src()` / `SourceLocation`, `io/fs`, `path`, `io/env` / `io/os`, `mkdirRecursive`, and the generic text methods (`normalizeNewlines`, `trimTrailingNewlines`, `firstDifferingLine`); a primitive the engine lacks is std surface first, never a host cell in `snap` (391 (2), 402). Contract 7's snapshot half is `snap`'s; every `<lib>-test`'s `assert<Subject>` writes through `snap` (391 (3)); the consumers moved one commit per library (391 (4)); `snap` runs where `io/fs` does (391 (5)). A test's location reaches `snap` through a `syntax` parameter — `snap.matches(render(page))` with `pub fn matches(syntax value: unknown) -> anyvalue`, a function expanded at its call whose build body reads the call's location with `compiler.source(value)` (`Source(file, line, col)`) and returns `` code @`snap.matchesAt(${value}, ${at})` ``, writing the test's file and line into every call (719); the snapshot's name is the running test's, set by the test runner where `matchesAt` reads it, the location only placing it in the file (772) —, or as an explicit `comptime compiler.src()` argument, an ordinary parameter the test writes, a call without it refused by the ordinary arity check — `src` being a function of `Compiler`, `fn src(self: Self) -> SourceLocation`, always written with its parentheses (718); a default `at: SourceLocation = comptime compiler.src()` would name snap's own module and gets no exception (719, 718). The nine snapshot maps of 1.0.10 are closed records; no front records a `.snap` because a map names it; the `.snap` files that exist stay and change only with their test; a new snapshot only where its exact bytes are read by another package (`rakun-ssr`'s release `text_…` and `dockerfile_…`, onze-release's before 724); helpers no more than a consumer uses; the 21 values nothing verifies become plain tests (390). An `FsError` carries its own text, `e.message()`, so snap's local `fsText` helper is deleted (563).

**Refusals loaded by the compiler.** `snap` records none: `matchesRefused` left the library with its cell (796; 784 (2)–(3), 786 (3) overtaken) — the conformance suite records a loaded case by what its package prints (789 (4), (5)).
