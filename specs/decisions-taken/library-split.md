# library-split — which library owns what

**The shared libraries are repositories and ordinary dependencies; the compiler ships std alone; a package exists only for two or more consumers and exports no colliding name; what is generic goes to std, and std names no library.**

(1) Libraries as repositories; when a package may exist; no colliding export — 326, 657, 932, 163, 946.

(2) rakun's workspace: `rakun-release`, the examples — 917, 935.

(3) Snapshots: `snap`, the closed maps, std's pointer — 391, 390, 407.

(4) Data formats, the persistence layer, `query` — 396, 398, 312.

(5) The CSS layers, `log`'s sinks, the `cli` library — 338, 349, 506.

(6) The 1.0.10 seams between rakun, rakun-bpp and rakun-ssr — 114, 117.
