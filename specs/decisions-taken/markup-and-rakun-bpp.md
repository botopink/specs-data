# markup-and-rakun-bpp — tags, holes, slots, directives, native elements

**A tag's attributes are its component's props; a hole accepts a closed list the template decides; a component's content is its default slot; template directives are annotations written inside the tag; a native tag is typed as React types its intrinsic elements.**

(1) **Holes and nodes.** `rakun-bpp`'s templates accept in `{expr}` a closed list: a `string`; a number of any numeric type and a `bool`, each as its `toString()` text; a component the template renders (a `Component<Element>` value); a list of such components; and `Node`, the name of that set — `import {Node} from "rakun-bpp";`, replacing `JhonstartNode` and `Children`; any other type is a comptime error at the expression (191, 223). A hole of type `?T` is a comptime error at the hole (`write {subtitle ?? ""}`) (204). The library decides which types an embedded expression may have (190). `rakun-bpp` declares `pub type View = Component<Element>;` — a type alias, the same type under a shorter name; a decorator that checks a component's return compares the resolved type (276).

(2) **Attributes and slots.** A component's attributes are the fields of its props: each attribute name one of those fields, each value of that field's type; an undeclared attribute, a value of another type and a field with no default left unwritten are comptime errors at the attribute (192, 529). A component's content is its default slot, read with `<Slot />`; no `children` field; content inside the tag of a component that writes no default slot is a comptime error at the tag (193). Slots work as Astro's, in annotation form: `<Slot name="footer">fallback</Slot>` declares and renders the named slot; a direct child annotated `#[slot("footer")]` fills it, several as a list, `<Fragment #[slot("footer")]>` with several nodes; `<Slot name="footer" #[slot("footer")] />` transfers; `val has = use hasSlot("footer");`; `Slot` and `slot` are `rakun-bpp` functions evaluated when `html` expands, recording typed meta the template reads by type — the compiler knows no slot; the name is a markup label, a string; checked at build: a misspelt slot names the slots the component has, content for a slot the component does not write is an error at the child; the content reaches the component through a hidden argument; lowercase `<slot>` is the native element (360).

(3) **Directives.** Template directives are annotations written inside the tag, in the attribute zone: `<Carousel #[clientVisible("200px")] images={12} />`; Astro's `prefix:name` syntax is gone; the names keep the side as a prefix — `clientLoad`, `clientIdle(timeoutMs)`, `clientVisible(rootMargin)`, `clientMedia(query)`, `clientOnly`, `serverDefer`, `transitionName`, `transitionAnimate`, `transitionPersist`, `transitionPersistProps`, `isRaw`, `isInline`; `#[clientOnly]` is one function with one meaning — on a hook declaration 186's marker, on a component tag the instance is never rendered on the server and records `Hydrate.Only`; what an annotation does is the typed meta it records — `Hydrate` → an island, `Defer` → a server island; `html` checks every `Hydrate`: the component carries `#[client]` (compared with `compiler.same`), a component whose hooks reach `#[clientOnly]` is refused under any `Hydrate` but `Only`; element directives: `set:html={s}` → `{raw(s)}`, `set:text={s}` → `{s}`, `class:list={[…]}` → `class={classList([…])}`, `#[isRaw]`, `<style #[isInline]>` (278, 302, 666). An island's fallback is an argument of its annotation — `<Avatar #[serverDefer(fallback: <GenericAvatar size={48} />)] size={48} />`, `<Map #[clientOnly(fallback: <p>Loading…</p>)] zoom={3} />` —, comptime: static markup or a component without request data (287). A link's instructions are tag annotations, `<a #[reload]>` and `<a #[history(.Replace)]>`, lowered to `data-rakun-reload` / `data-rakun-history`; the five navigation events are `#[clientOnly]` hooks with typed events (`use onBeforePreparation(…)`, …); `<Script>`'s strategy is its own enum prop (292). A browser-only cell is `#[clientOnly]`, reached only through a `#[clientOnly]` hook, never given a server twin; the erlang twins answering the server's empty truth are deleted; a server-rendered `Link` reads no hook — its pending state is `data-rakun-pending` set by the client router, styled with CSS (363). Outside markup, expression-level work is a call (`traced(compute())`); a tag's annotation is the one expression-position decorator, and `val x = #[deco] 1;` stays refused (705). A template body tells annotations apart by the meta they recorded (679).

(4) **Native elements.** Each native tag is a `rakun-bpp` builder whose first parameter is the element's props record — the rule of a component —, so `<a hreff="/x">` is a comptime error at `hreff`, content inside a void element at the tag; the props are records layered with `Type.merge` (`GlobalAttrs`, `AriaAttrs`, each element's own: `pub val AnchorProps = Type.merge(Type.merge(GlobalAttrs, AriaAttrs), AnchorAttrs);`); a field is `?T = null` or a `bool`, a number `i32` / `f64`, a closed set an enum (`target={.Blank}`), the rest `string`; a one-word attribute keeps HTML's name, a multi-word one is camelCase as in React, the renderer writing HTML's; `aria-*` are typed fields of `AriaAttrs`; `data-*` is the one open family; a native tag exists in markup only when the prelude names its builder — a custom element or an unlisted SVG tag is an error at the tag; spread on an element takes a value of that element's props type; an event attribute (`onClick`) is refused at its name until a front declares typed events (351). `05-jhonstart/26` rewrites the native builders into that form in place, one builder per tag, never two, and the 78 hand-written callers with them; `el(…)` stays the escape hatch (362). A template hole writes `print`'s text for every value (530).

(5) **Errors and boundaries.** The runtime hands the error boundary the caught error's class and frames; the boundary calls `log`'s `logError` with `module` the boundary's route segment (220). Error, not-found and `Suspense` boundaries are tree nodes holding component values, run by the renderer in plain functions taking `scope: Scope` (809 (8)) — `renderComponent`, `renderErrorBoundary` (the child under `attempt`), `renderNotFound`, `renderSuspense` —; an application writes no try around children; the file conventions (`error.bp`, `loading.bp`, `not-found.bp`) do not change (414, 504). `rakun-bpp`'s renderer is the first library to give its pure cells a wasm form (594 (2)). `rakun-bpp-dom-test`'s `fake_dom.mjs` holds `<form>`, `<input>`, `FormData` and `submit`; the DOM-side forms boxes are asserted in its `forms_dom_test.bp` and again in the ssr's browser run (940). jhonstart and its members are now the workspace package `rakun-bpp` (724). An HTML marker carries the prefix of the package that writes it — `rakun-bpp`'s are `data-rakun-*` (113 (4)); a browser global exists only where the HTML names it by text and its name is generated, `__bp<N>` from `rakun-bpp`'s globals registry (`globals.payload`, `globals.fill`, `globals.signal`), none written by hand (113 (6), 117 (2), 140). `rakun-bpp`'s `RenderPlugin` is asynchronous — `head()`, `chunk(holeId)`, `close() -> Async<Result<void, string>>`, `payload() -> Async<?#(string, Json)>` once after `close` —, a payload key the render writes itself or two plugins give failing the render; `rakun-stylesheet` enters through it as a plugin (113 (7), 114 (2), (3), 120). Track 05's choices stand so (953): every router cell dual-target; the island starters per route through `registerRouteStarters(pattern, load)` over `globals.starters`, each `#[client]` registering through its `compiler.init` executor, no per-name `registerStarter`; `compose(chain, Page())` runs the layouts first and takes the page as a component value, never a thunk; `Suspense(Boundary(id, fallback, child))` a node with `child: Component<Element>`, no host-cell registration; the segment record `UiSegment`; `app(…, lang = "en")` one checked language per app (`isLangTag` until `i18n`'s subset, 180); the browser half in `rakun-bpp-dom-test`; `notFound()` / `redirect(url)` raise through one host cell, a boundary captures through one, `notFoundReason()` / `redirectReason(url)` answer without raising — their signatures `nat-d6`'s and `lg2-l`'s.
