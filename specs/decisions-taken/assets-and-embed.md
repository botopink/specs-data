# assets-and-embed — `compiler.embed`, `Link`, `Asset`

**`compiler.embed(path)` makes the link and nothing else; `Asset` opens a `File` over it; when the file is read is the `comptime` written at the read.**

`compiler.embed(comptime path: string) -> Link` resolves the path relative to the `botopink.json` of the package that writes it (a path passed through a `comptime` parameter in its caller's package), keeps the refusals `embed-path-absolute`, `embed-path-outside-package`, `embed-file-missing`, `comptime-arg-not-known`, `embed-no-reader` (the CLI and the LSP read the disk, `compiler-web` refuses), records the file as an input of the build (its hash in the cache key; watch and the LSP rebuild on change) and answers `Link(path: string)`; it reads no byte; in a run-time body it is written under `comptime` (607 (1), 519, 342). `asset.bp` — `import {compiler.Link, io.fs} from "std"` — declares `pub type Asset(link: Link) { pub fn open(self: Self) -> Result<File, FsError> { return fs.open(self.link.path); } }`, made by its constructor: `val logo = comptime Asset(compiler.embed("assets/logo.png"));`; reading is `File`'s — `read`, `bytes`, `text`, `lines`, `hash`, `size`, every one a `Result<…, FsError>`; `Asset.path` / `.bytes` / `.size` / `.hash` / `.text()`, `File.ofBytes`, `openAsset` and the refusals `embed-text-not-utf8`, `embed-text-not-at-build`, `embed-open-needs-fs` are gone — one file-reading API, `io.fs`'s; a `Link` is made by `compiler.embed` alone, so an `Asset` always holds a path the build checked (607 (2)). The file is read when the `comptime` written at the read says: `val bytes = comptime { val f = try logo.open() catch panic("logo"); try f.bytes() catch panic("logo") };` reads at build and the bytes are a constant of the artifact (an Erlang binary, a JS `Uint8Array`, a wasm data segment); `val f = try logo.open() catch panic("logo");` reads when the program runs, so the file is deployed with the program; a failure at build is a located build error (607 (3), 519, 520). `fs` stays refused in a comptime body otherwise (342). The behavior `Compiler` names `SourceLocation` and `Link`; `Asset` is no concern of it (607 (5)). A path reaching a function through a `comptime` parameter is handed as a hidden last parameter, one body per function (538; the rest of 538 — `size`, `hash`, `open()` without a `Result` — is 607's and 540's).

In the resolved program's print an `Asset` is `Asset(Link(path: "…"))` and read bytes `bytes.fromHex("…")` (885).
