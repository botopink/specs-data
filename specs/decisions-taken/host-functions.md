# host-functions — `declare fn`, `#[compiler.external(…)]` and `Implementation`

**A bodyless `declare fn` names its host sources with `#[compiler.external(…)]`; a source is host code a target runs, written by its label; a call with no cell for the active target is refused.**

(1) The form: `declare fn`, `compiler.external`, the `Implementation` enum, `$N` / `$args` — 311, 437, 604, 610, 618, 795.

(2) Labels and cells: `body:`, `op:`, `std:`, `wasi:`, `host:`, `needs:`, `result:`, `inline:`; prefixed strings refused — 238, 305, 445, 481, 487, 491, 502, 516, 621, 847, 918.

(3) Strict on every target: a missing cell refused at the call; reached-only lowering; `needs` gathered — 146, 503, 518, 531, 597.

(4) Failure of a host: `result: true`, `HostError`, `Failure`'s kinds, which calls are wrapped — 488, 489, 490, 492, 495, 527, 546.

(5) At build: only the wasm form runs; math's `std:` cells — 341, 452, 594, 764 (633 overtaken by 594).

(6) Bodyless type methods; `string` bodies on wasm — 311, 565, 879.

(7) `io.fs`'s shape; WasmGC's fronts — 540, 544.

(8) Superseded here: 652 by 575, 862 and 889 by 975.
