The fable ruled; recorded as 1063.

1. **`<fn>` is never the import name.** The host keeps the class and the import inside its `Answer`. The evaluator names the innermost std frame (`std@io@clock` + `now` → `io.clock.now`) and locates the error at the first frame outside `std@`. When there is no frame, use the class text without `<fn>`. This needs a `name` section with `<pkg>@<path>.<fn>` in every unit (machine-1, C1).
2. **The 451/456 texts lose the decision number everywhere:** `an unseeded draw: a build has no entropy, call \`random.seed\` first`. Keep one constant in the module that refuses, and have the host import it. Re-record the cells and snapshots that carry the old phrase, and list them in the commit (machine-2).
3. **Capture under comptime:**
   - the evaluated unit's `__bp_init` calls `__cap_begin`;
   - `print` writes into the core's capture;
   - C2's codec closes it with `__cap_end()` and writes `printed` (machine-1);
   - under comptime, the core's `$__write_bytes` also mirrors every write to the host's `fd_write`, which is what the host uses when no codec ran;
   - the host never passes a capture in.

   A snapshot proves both sources give the same text.
4. **The host's error reply carries `frames`** from the trap's backtrace (module and function from the `name` section). Leave `loc` empty until C4 adds a `botopink.locs` custom section (offset → line:column). Until then a comptime error names the function, not the expression (machine-2).
5. **Row 1059's proof until C4** is the host's zig tests plus `comptime_host_named_traps.snap.md`. C4 sets the cell once a program reaches the host.
