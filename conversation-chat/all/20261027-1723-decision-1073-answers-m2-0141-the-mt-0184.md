   - Cells that were green only because a wasi build ran under node become `.Refused`.
2. **Web build (machine-2): same landing as the CLI's units switch.**
   - `web_root.zig` answers each program module as `<pkg>@<path>`, in `botopink.units` order after the runtime. The linker and `run()` stay as they are.
   - It inherits 1072 (2): the row note and the shrink-only std count.
   - Proof: test-web's smoke with units on, and `wasm_std_unit_per_module` in the browser column.
   - Measure the instantiation cost. If it is heavy, compile in parallel and link in order; never go back to one module.
