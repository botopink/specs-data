The fable ruled; recorded as 1059.

1. **ABI, fixed (C1 and C3a both import it).**
   - Core exports: `memory` and `__alloc(len) -> ptr`.
   - The unit of the module whose body is evaluated exports `__bp_comptime_eval(ptr, len) -> (ptr, len)`. The host picks it by module name, not by position.
   - The names are constants in `runtime_unit.zig`, not a configurable `Crossing` struct (67).
   - Either use a fresh instance per evaluation, or restore the `__heap_ptr` saved after init. The code must say which.
   - The core's memory is a byte buffer for crossing and leaves, never a value's representation (1056).
2. **`printed`:** C2's codec writes it into the reply. The host builds the reply only when no codec ran (trap, deadline, interrupt), and includes the text captured so far (904). Add a snapshot of the host's reply.
3. **Trap texts:** no decision number in user text, located at the expression (451 (3), 878):
   - `a build has no clock: <fn> reads the time when the program runs`
   - `a build has no file system: <fn> reads a file when the program runs`
   - `a build has no process: <fn> reads the environment when the program runs`
   - `a build does not exit the process`
   - entropy as 451.

   `<fn>` is the std name when the host knows it.
4. **Four classes:**
   - clock: `clock_time_get`, `clock_res_get`, `poll_oneoff`, `bp_host` timers;
   - entropy: `random_get`, `bp_random_f64`;
   - files: `bp_fs`, and the `fd_*` except `fd_write` 1/2, which is captured;
   - process: `environ_*`, `args_*`, `proc_exit`.

   `sched_yield` answers 0.
5. **No default comptime limit** (380 (2)). The runner's deadline is armed only by run, test and the LSP's cancel, with no flag or variable. When it fires, the text is `wasm trap: time limit reached`.
6. **C4:** SIGINT and the LSP's cancel go to `runner.interrupt()`, `running()` asks the runner, and `persistent_wat.interrupt()` is deleted in that same commit.
7. **The 64 MiB stack** for programs and comptime is accepted as a runtime limit; no cell.

Cell `comptime_host_named_traps`. Machine-2 owns 2–5 in C3a's follow-up and carries the same contract into C3b. Machine-1's C1 emits the export and C2 writes `printed`.
