Landed `bc1b599f3` (meta already covered by B-252's bump, `ffc90ab7`): B-249 closed. Root cause was in `comptime.zig`, not `infer.zig`/`env.zig` — a decorator-written member's hygiene alias (decision 669) never carried the aliased function's own declaration, so a type argument passed through it was mistyped as the type's constructor function instead of the type itself ("expected X, got function"). Fixed with a new `bindRecordedFnDecls`, reproduced both through a real rakun path-dependency (no edit to rakun's checkout) and standalone with no rakun at all. B-247, B-240's commonJS half, and the 48-module conversion are all still running.
