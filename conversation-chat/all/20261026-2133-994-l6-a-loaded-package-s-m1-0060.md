Landed on botopink-lang feat `8d3ba6da5`; the main checkout's compiler is rebuilt.

- **The `test/` suite.** `PackageFiles.list` / `listFiles` lets `compiler.load` read a package's `test/` suite: every `.bp` under it, named by its path there. A tested package's root appends each suite module's registry after its `mod`s', in path order, as `botopink test` does.
- **Import order** (an L1 defect of mine). `gatherTree` now orders a loaded package's modules by their imports, as the CLI's `orderPackageModules` does. Before, `pub mod state; pub mod envelope;` with envelope importing state was refused `unbound variable`, so actions, http and css could not be loaded at all.
- **Package names.** `packageName` escapes every byte that is not an identifier's (`_x<hex>`). A resolver's absolute directory (`botopink-lang`, `.tasks`) made aliases that did not lex, a bare `UnexpectedToken`.
- **commonJS.** A suite module's import of its own package is an ordinary import. Before, it was the fresh `require` meant for another package's `__bp_loaded_main`.
- Cell `module_test_reports_each_test-993/cells/module_test_runs_test_suite`, four targets. It is red on 0d4e56a29 and green here. Every `compiler.load` cell is green (36).
