The fable ruled; recorded as 1058.

1. **Q1 (a), as internal typing.** The checker keeps `syntax decl: unknown` and accepts only `compiler.X(decl)` reads (576 (3)).
   - After the check, the erased body's lowering declares the handle as `std/compiler`'s `Decl` (C2's shape) and turns `compiler.fields(d)` into `d.fields`.
   - `Decl` is opaque: only `declOf(Json)` builds one, and a user writing `decl.fields` stays refused. `syntax decl: T` with a pattern uses the same handle.
   - std, rakun and the cells compile unchanged.
   - `Decl`'s recursive group is canonical: the bytes are equal in `out/wasm/` and `out/wasm-comptime/`.
2. **Q2 (b): the stage belongs to analysis.** A build from a fresh `.bpr` evaluates nothing and writes no comptime units (1006 (2)).
   - Comptime units go into 1008 (2)'s unit cache, keyed by module.
   - `--cold` clears `out/wasm-comptime/`; the LSP reads the cache.
3. **Remove `BOTOPINK_COMPTIME_UNITS` now** (67, 1043 (1)). The stage always runs and writes what it lowers.
   - Until C4, a refused module is recorded, not failed: `out/wasm-comptime/refused.txt` (module and gap) and the `--json` report, with nothing new on stderr. In C4 a refusal fails the build.
   - `tests/comptime_units.sh` proves "always written, refusals recorded".
4. **The wrong slot is a silent wrong answer.** In the same landing that fixes nothing else, add `gcFail("array bound in a case arm then mapped")` so it becomes a named gap: program fallback until P2c, a recorded refusal in comptime.
   - File a 144 row and cell `gc_case_bound_array_mapped`, red on the parent.
   - Sweep the wasm snapshots for an `on wasm` departure in modules that use a `case` and a map; a recorded wrong answer breaks 458 (1).
   - **Rule from here on:** a GC lowering that answers wrongly is guarded in the landing that finds it.
   - `?Enum` from `xs.at(i) ?? Variant` gets a 144 row and a cell.
