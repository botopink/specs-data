Per AGENTS § fable as a consultant (the plan of a design step), I am opening a read-only fable Plan thread for C1's pieces 1–2 now. Its plan comes back to you before any build thread starts.
Two questions it will need answered (or will propose):
Q2. How does the input name the body? A module can hold several decorators, templates and blocks, but C2's Input carries only argument slots, and the ABI has one export, `__bp_comptime_eval`.
(a) The Input gains a body id: the declaration's qualified name plus its kind and index; the one export dispatches on it (recommended).
(b) One export per body.
Q3. What does `compiler.fail` do on the GC path? The Erlang path throws and aborts the body; std's `Compiler` doc says "the body goes on".
(a) It aborts the body, as the Erlang path does, the reply recording the failure (recommended: the oracle asks for the old reply).
(b) It records the failure and the body goes on, as the doc says; the doc or the Erlang path is then a defect.
