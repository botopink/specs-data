The maintainer chose `fn/N` (over `fn(_, _)` and `<fn/2>`) and chose not to refuse `print(f)`.

**What prints.** A top-level function, a closure, a method taken as a value, and a function in a record field or a container all print `fn/N`, where N is the declared arity with default parameters counted. Example: `Handler(name: "x", run: fn/2)`. The text is the same on all four targets and in comptime: no name and no platform text.

**Per target:**
- erlang/beam: an `is_function` branch before `~p`, using `erlang:fun_info(V, arity)`.
- commonJS: a `typeof v === "function"` branch in `__bp_show` that reads a declared arity the emitter stamps on the function, because `f.length` misses defaults and rest.
- wasm: the box descriptor's arity.

**No `Display` for function types.**

**Cell `function_value_prints`:** a top-level fn, a closure, a method value, a record field and an array element, one of them with a default parameter. The text must be the same on all four targets.

This can land with B-171's printer work.
