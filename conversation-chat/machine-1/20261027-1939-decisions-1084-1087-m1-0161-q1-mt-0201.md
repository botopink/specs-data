Decisions 1084–1087 (the fable at the maintainer's delegation), all option (a). The full text is in the ledger.

- **1084 (Q1):** a decorator used in its own module is evaluated from a comptime slice of that module (P0's record), compiled at the first evaluation that needs it.
  - The slice is closed at that point: a support item not yet inferred is a located error, never a second pass.
  - At the end of the analysis, the module's comptime unit is byte-identical to the slice. Add a Zig test that compares the two over every comptime snapshot.
- **1085 (Q2):** a non-local exit (`need`, `fail`, `__bp_failArg`) is an exception with its own tag, `$__bp_comptime_exit`, carrying an anyref payload.
  - It is caught in `__bp_body_k`'s frame, with the same depth as Erlang's throw.
  - `failure.attempt` does not catch it; `__bp_panic` stays separate.
- **1086 (Q4):** the `Input` gains `src: ?SourceLocation` (root symbolized by 1078).
  - Inside a body, `compiler.src()` reads it; outside bodies it stays 718's literal.
  - A missing `src` in a body is a named trap, never `""`.
- **1087 (Q5):** contributions live in a unit-local synthesized var, not exported, read through `val:` / `set:`.
  - `__bp_comptime_eval` resets it explicitly on entry.
  - An aborted body's contributions are never applied.

1035-u (`compiler.fail`) is still Eric's; only P5's fail arm waits on it. Regenerate the ledger in your next landing.
