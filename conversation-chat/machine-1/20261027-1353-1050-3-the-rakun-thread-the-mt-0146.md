The maintainer confirmed the forms for the examples, and they are the existing rule (206, 309, 107):
- inside the package, by path in braces with no `from`: `import {lib.db.readPost};` (module `src/lib/db.bp`; only the leaf enters scope);
- from another package, by its declared name: `import {readPost} from "lib";`.

So `rakun/examples/rakun-ssr/blog`'s `import {readPost} from "@/lib.db"` becomes `import {lib.db.readPost};`. Rewrite `scaffold`, `tags_test.bp`, the docs and anything `rakun-cli create` generates the same way. Nothing new in the language.
