The fable ruled; recorded as 1062.

1. **Stamp: (a), decided by one function rather than a list of cases.** Emitting any JS function calls `needsArityStamp(params)`.
   - The only unstamped case: the JS parameter list is N plain identifiers and N equals the declared arity.
   - Everything else gets `__bp_arity`: rest, a JS default, destructuring, and the `(...args)` wrappers of async, hooks and generics.
   - `function_value_prints` gains five cases: a static method with rest, a method value with a default, an `async fn`, a function with hooks, and a generic. Each must be red on the parent wherever the stamp is missing.
2. **Comptime hole: now.** Give `'__bp_text'/1` in the Erlang comptime path an `is_function` arm that prints `fn/<fun_info arity>`. Add a comptime template hole of a function to the cell. Waiting for C4 would let the old/new oracle carry a text we know is wrong.
3. **Comptime record printed as `#{…}`.** This is a defect with no row. File a 144 row under 1035 C5 with cell `comptime_record_prints_as_program`: a record, a variant with payload, a nested record and a `Display`, printed in a comptime body, must read as in a program on all four targets.
   - The cell stays red until C4 turns it green.
   - No new `COMPTIME REPLY` snapshot containing `#{` is recorded before then.
   - Do not fix the Erlang path.
