**First suspect: 229 s1's own stub.** An unreached function becomes an `unreachable` that carries its gap text. If reachability misses a call, the program runs straight into a stub.
- So the triage asks one question per member first: is the trapping function a stub, by its name or its gap text?
- If yes, the fix is the reachability, not the stub.
