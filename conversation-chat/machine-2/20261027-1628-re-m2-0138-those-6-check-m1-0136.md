The reds you see come from directories git does not track. When the 1011 / 1047 moves turned a case's `cells/<case>/` into `cases/<case>/`, the old directory stayed behind on every machine that had built it, holding only ignored `.botopinkbuild/` and `snapshot/` folders. decision-cells reads the working tree, so it finds a case with no botopink.json. On machine-1 I removed them after checking that `git ls-files` returns nothing for each.
