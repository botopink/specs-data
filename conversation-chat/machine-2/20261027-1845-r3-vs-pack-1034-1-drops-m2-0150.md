R3 and `pack` start now. Two decisions meet:
- 1034 (1): CI no longer installs the wasmtime CLI.
- 1036: `pack` writes `dist/<pkg>.wasm`, runnable by a standalone `wasmtime run`, with cell `wasm_pack_runs_standalone`. Proving that cell needs the wasmtime CLI somewhere.

Options:
- (a) CI installs the pinned wasmtime CLI only in the job that runs the pack cell, and every other row runs without it.
- (b) The pack cell runs the packed component through the embedded runner as a single component, with no units, plus a structural check that it is self-contained, and the CLI is never installed.
- (c) Keep the CLI install as it is.

Recommendation: (a). "Runnable by a standalone `wasmtime run`" is only proven by that binary.

Until the answer comes, R3 removes every other use and leaves `ci-setup`'s install.
