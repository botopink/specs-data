Everything is in `modules/compiler-core/src/comptime/load.zig`, reached through the core's `load` module:
- `root_symbol_prefix` = `"bp-root:"`; `RootSymbol` is a fixed-size array: the prefix followed by 64 hex digits.
- `rootSymbol(load_dir) RootSymbol` = the prefix + lowercase hex of `sha256("botopink-load-root-1\0" ++ load_dir)`.
- `rootLoadDir(arena, cache_root: ?[]const u8, dir) ![]const u8` gives the hashed text: `dir` relative to the loader's cache root with `/` separators, `.` when they are the same, the absolute `dir` when there is no cache root. It equals the CLI's `NameResolution.found.shown`, so the key file maps a symbol to this string.
- `registerRoot(load_dir, real) !RootSymbol` records an entry for the whole process; a new real directory for the same symbol replaces the old one (1039 (3)). `compileFile` registers each by-name load it reads.
- For desymbolize: `rootOfSymbol(symbol) ?RootEntry`. For symbolize: `rootOfDir(real) ?RootEntry`. For the key file, in order: `rootEntries(arena) ![]const RootEntry`. `RootEntry` = `{ symbol, load_dir, real }`, its strings living as long as the process.
- Unchanged: the fold emits the real path, so a program prints the resolved directory (1078 (4)).
